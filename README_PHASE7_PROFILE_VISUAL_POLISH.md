# Phase 7 — Player Profile Visual / Interaction Polish

Frontend-only polish based on the working Phase 6 profile state.

## Changes
- Sticky Player Profile top section: headshot/identity, context controls, radar, and six-dimension SDI remain visible while scrolling the profile card.
- Sticky horizontal table scrollbar at the bottom of the profile card's visible area, synchronized with each table.
- Individual selected seasons now highlight the entire row with the site's soft red accent, including the sticky YEAR cell.
- No API, data, SDI, percentile, WOWY, or headshot files are changed.

## Install
Copy:
- `src/App.jsx`
- `src/player_profile_visual_polish_phase7.css`

Do not replace `local_api` or existing headshot assets.
