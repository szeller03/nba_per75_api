# V6 — Career View + Context Profile + Custom Spider Restored

- Added a Career option to the player season selector.
- Career view summarizes the existing season-profile/statistical records.
- Career percentiles are intentionally not fabricated by averaging percentile ranks.
- Added a dedicated Context spider mode for Offensive Role / Usage, Shot Profile, and Availability / Foul Context.
- Restored 46-stat custom spider selection.
- Custom statistics continue to support Season/Era/Historical when a season is selected.
- Dominance, Context, and Custom 46-stat spiders are now distinct modes.
- No source/master data is modified.
