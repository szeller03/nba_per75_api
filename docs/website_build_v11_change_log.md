# V11 — Season-Wide Big Board

Built the first functional Big Board surface.

Features:
- Season selector sourced from the validated visualization Big Board dataset.
- Season / Era / Historical percentile context selector.
- Rank by Statistical Dominance Index or any registered statistic.
- High-to-low or low-to-high sorting.
- Player search/filter.
- Player rows link to the canonical player profile.
- Value and percentile are displayed together.
- Uses the existing website API layer; source/master analytical data is not modified.

This is the functional baseline. Visual refinement can be done later.
