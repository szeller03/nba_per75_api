# Website269 — Create Your T75 Direct Player Card Pool

Implemented the direct-selection player pool as a selectable card deck instead of compact horizontal bars.

## Changes
- Replaced the direct player pool rows with visual player cards using existing player headshots.
- Added larger artwork, rank index, add/added pill, player name, and position/history label.
- Added stronger hover lift and gold selected state.
- Preserved exact selection behavior, target limits, search, reorder panel, profile output, and sharing.
- Responsive card density: 4 columns desktop, 3 at medium widths, 2 on mobile.
- The existing chooser / head-to-head method and final list outputs were left intact.
