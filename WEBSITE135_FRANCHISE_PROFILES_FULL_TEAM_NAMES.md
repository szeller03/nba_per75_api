# Website135 — Franchise Season Profiles + Full Team Names

- Franchise-search season rows are explicitly clickable and open the existing
  Team Profile for that exact team-season.
- Profile lookup now normalizes franchise identity, so abbreviations and full
  names resolve to the same team-season.
- Team display names are expanded from abbreviations to full franchise names
  (e.g. BOS -> Boston Celtics, OKC -> Oklahoma City Thunder, GSW -> Golden
  State Warriors).
- Franchise search still accepts common abbreviations and full names.
- A small "View profile ->" affordance was added to clickable season rows.
- The existing statistic sorting behavior is preserved.
