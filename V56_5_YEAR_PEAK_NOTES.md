# NBA PER-75 Website V56 — 5-Year Peak

Implemented the locked-in 5-Year Peak Big Board scope.

## Methodology
- Regular season only for this release.
- Each included season must meet the existing regular-season percentile qualification threshold.
- Five qualifying seasons are required.
- The five seasons must fit within a maximum six-calendar-season span.
- One skipped/non-qualifying season is allowed.
- Two consecutive skipped seasons are not allowed.
- No Era Average thresholds apply.
- The statistic is aggregated from the underlying player-season data using the existing aggregation contract.
- Each player contributes one best peak for the selected statistic.
- Era filtering remains available; a peak is assigned to the era containing its starting season.
- Peak rows display the actual five included seasons and identify any skipped season.

## Other
- Statistical Dominance Index remains unchanged.
- Playoff 5-Year Peak is intentionally not exposed because its methodology has not been separately defined.
