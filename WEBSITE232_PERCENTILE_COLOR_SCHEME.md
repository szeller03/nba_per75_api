# Website232 Percentile Color Scheme — Blue / White / Red

Integrated the site-wide percentile visual treatment requested by the user.

## Scale
- 0th percentile: red
- 50th percentile: white / neutral
- 100th percentile: light blue
- Continuous interpolation between those anchors

## Applied to
- Player Profile seasonal percentile badges
- Big Board primary-stat percentiles
- Team Profile Season / Era / Historical percentile badges

Percentile values remain rounded to whole numbers. The percentile calculation/source is unchanged; this patch only changes the visual grading.
